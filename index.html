Deskripsi Program To Do List

Program ini adalah aplikasi To-Do List sederhana yang dibuat menggunakan HTML, CSS (Bootstrap), dan JavaScript. Digunakan untuk mencatat kegiatan.

Fitur:

  • Menambahkan tugas beserta tanggal kegiatan.
  • Mencentang checkbox jika tugas selesai.
  • Mengubah (Edit) tugas yang sudah ada di tabel.
  • Menghapus tugas dari tabel.
